# 60分境界・永続観測候補

状態：実装候補、オフライン14試験合格。未デプロイ、新規実時間観測なし。

既存の署名・OIDC/B2検査を変更せず、元のadvanceをワーカーから呼ぶ。START、各TICKの実行前/後を同期コミットし、期限と乱数run ID、時刻、判定booleanだけを記録する。トークン・subject・SID・nonce・署名封筒・それらのdigest・例外本文は記録しない。実行時の認証結果の同一性照合は元のadvanceで維持し、その比較材料はメモリにのみ保持する。

画面消失後も常駐ワーカーが稼働していれば続行できる。保存済み結果はJournal.recover(run_id)で新プロセスから回収できる。プロセス停止で失われた秘密のpending封筒は復元しない。TICK_BEGINで記録が終われば未完扱いとし、新セッションで補完しない。通信後の保存失敗も自動再送しない。

採用前に必要な接続：

1. **永続実行基盤**：単一の監督付きサーバーと永続ボリュームの実在、再起動/再配置後の存続、バックアップ、権限を確認する。現行Streamlitの一時ディスクを永続ストアと見なさない。SQLite候補は単一ホストの複数プロセスを対象とし、複数ホスト/ネットワーク共有DBの保証はしない。複数ホストならトランザクションと比較更新を持つ外部DBアダプタへ置換する。
2. **正規実行アダプタ**：Streamlitスレッドに依存しない、正規認証済みセッションのサーバー側引渡しと現在の署名/失効検査へ接続する。フォーム/手入力claimsから本人を生成するアダプタは不可。現時点ではこの実環境アダプタは未接続。
3. **稼働前確認**：本物の保存先で再起動後の回収・アクセス制御・保存不能時無送信を実測し、独立技術レビューを受ける。外部保存先や新たな秘密値を黙って作成しない。
4. **実時間測定**：原OIDC iatと固定期限に基づき同じセッションで観測。期限直前の許可、期限後新規署名拒否、期限を揃えた既発行封筒のGAS拒否を記録する。テストの人工時計を実機結果に加算しない。Cookie/再読込は別UI証拠を対応付ける。
5. **真正性**：SHAチェーンは偶発破損検出であり管理者による偽造防止を保証しない。独立した読取保全先へのhead保存、アクセスログ、信頼できる時刻源、元GASイベントとの照合が必要。鍵や本人情報を証拠へ追加しない。

今回のSQLite試験は一時ディレクトリ上であり、実環境の永続性を証明していない。この候補だけでは60分境界PASSも運用準備完了も宣言しない。
