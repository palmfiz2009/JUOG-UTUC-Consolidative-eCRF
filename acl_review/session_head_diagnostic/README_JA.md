# セッション末尾照合（未反映の読取専用候補）

診断は既存隔離GASの管理者エディタで一度だけ実行する候補です。実環境へのファイル追加・実行は個別承認後とし、デプロイは不要です。現時点で反映も実行もしていません。

`diagnostic.gs`は固定Script ID・隔離Sheets ID・世代を照合し、AUTH_CONNECTかつauthConnectReviewApproved=falseでのみ読取します。Script Lockの取得・解放と固定形式の診断ログ以外に状態を変更しません。取得するプロパティはUNIFIED_ISOLATION_CONFIGと対象JUOG_B2_HEADだけです。秘密鍵・Secrets・全プロパティを取得しません。

実行関数は`juogReadOnlySessionHeadDiagnostic`です。ログには件数・一致真偽・固定結果コードだけを出します。エディタのプロパティ画面や秘密情報画面を撮影しないでください。

HEAD_BEHIND_VALID_CHAINなら、保存されている照合値が過去の行に一致します。ただし履歴のハッシュは署名ではなく、イベントの正当性を証明しません。MATCH以外も含め、この結果だけで照合値の更新、鍵の再交換、世代の変更、セッション復活、通信再開をしてはいけません。

12件の隔離ローカル試験に合格しました（`node test.cjs`）。これは実機結果・独立技術レビュー・正式UATの代替ではありません。秘密値を含む例外の非露出、対象不一致、停止未確認、チェーン異常、重複OPEN、先行/後退/不正head、ロック失敗を確認しています。

現在の停止解除には、実行元・現行コード・実設定の一致、末尾2件の真正性と照合値が戻った原因の確認、安全な修復方法のレビュー・限定承認が必要です。保存された台帳と監査は削除・上書きしません。
